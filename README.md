# רשימת קניות משפחתית

```
Instinct  ⇄  Google Tasks  ⇄  גיליון Google (Apps Script)  ⇄  אפליקציה בטלפונים
```

- `apps-script/` - השרת: קוד שיושב בתוך גיליון Google בחשבון ה-Gmail הפרטי. API לאפליקציה + סנכרון כל דקה מול Google Tasks.
- `docs/` - האפליקציה (PWA). מתארחת ב-GitHub Pages, נשמרת בטלפון ועובדת בלי אינטרנט.

## איך זה עובד
- כל רשימה באפליקציה (קניות, פארם...) = רשימה באותו שם ב-Google Tasks.
- ב-Tasks נמצאים רק המוצרים שעוד צריך לקנות. Instinct מוסיפה = מופיע אצל כולם. Instinct מסמנת בוצע / מוחקת = עובר ל"נקנו".
- V באפליקציה = המשימה נמחקת מ-Tasks. מוצר שנקנה נשאר בהיסטוריה של האפליקציה, ומוצע שוב כשמקלידים.
- בלי אינטרנט: השינויים נשמרים בטלפון ונשלחים כשחוזרת קליטה. אם מישהו שינה את אותו מוצר בינתיים - השינוי שלו נשאר.

## התקנה - חלק 1: השרת (פעם אחת, בחשבון ה-Gmail הפרטי)
1. sheets.new ← גיליון חדש בשם "רשימת קניות משפחתית".
2. תפריט הרחבות ← Apps Script.
3. בעורך: ⚙ הגדרות פרויקט ← לסמן "הצגת קובץ המניפסט appsscript.json".
4. להדביק את `apps-script/appsscript.json` לתוך appsscript.json, ואת `apps-script/Code.gs` לתוך Code.gs. לשמור.
5. לבחור בפונקציה `setup` ← הפעלה ← לאשר הרשאות (Google יזהיר "האפליקציה לא מאומתת" ← מתקדם ← מעבר). ביומן הביצוע מופיע FAMILY_KEY.
6. פריסה ← פריסה חדשה ← סוג: אפליקציית אינטרנט ← הפעלה בתור: אני ← גישה: כל אחד ← פריסה. להעתיק את כתובת ה-/exec.

## התקנה - חלק 2: האפליקציה
1. ב-GitHub: מאגר ציבורי `family-shopping`, להעלות את התיקייה (או `git push`).
2. Settings ← Pages ← Branch: main, תיקייה: /docs.
3. הקישור המשפחתי:
   `https://<user>.github.io/family-shopping/#api=<כתובת exec>&key=<FAMILY_KEY>`
4. לפתוח בכרום בטלפון ← ⋮ ← "הוספה למסך הבית". משם: ⋮ באפליקציה ← "שלח קישור לבן משפחה".

## עדכון קוד השרת
אחרי שינוי ב-Code.gs: פריסה ← ניהול פריסות ← ✏ ← גרסה: חדשה ← פריסה (הכתובת נשארת אותה כתובת).
אחרי שינוי באפליקציה: להעלות את `sw.js` עם מספר גרסה חדש (`fs-v2`...) כדי שהטלפונים יתעדכנו.

## בדיקה
`test/test_sync.js` - סימולציה של Tasks וגיליון. `node test/test_sync.js` ← ALL OK.
